## ШАГ 1 — Создай проект в Firebase

1. Перейди на https://console.firebase.google.com
2. Нажми **"Создать проект"**
3. Введи название, например `launchpad-platform`
4. Google Analytics — можно отключить, нажми **"Создать проект"**
5. Жди ~30 секунд, пока проект создаётся

---

## ШАГ 2 — Добавь веб-приложение и получи конфиг

1. На главной странице проекта нажми значок `</>` (Web)
2. Введи имя приложения, например `LaunchPad Web`
3. **Не** ставь галочку на Hosting (GitHub Pages используем сами)
4. Нажми **"Зарегистрировать приложение"**
5. Firebase покажет объект `firebaseConfig` — скопируй его целиком:

```js
const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc..."
};
```

6. Открой файл **`firebase-config.js`** и вставь свои данные вместо заглушек `YOUR_API_KEY` и т.д.

---

## ШАГ 3 — Включи Authentication

1. В левом меню Firebase → **Build → Authentication**
2. Нажми **"Начать"**
3. Перейди на вкладку **Sign-in method**
4. Нажми **"Email/Password"** → включи первый переключатель → **Сохранить**

## ШАГ 4 — Включи Firestore

1. В левом меню → **Build → Firestore Database**
2. Нажми **"Создать базу данных"**
3. Выбери **"Начать в тестовом режиме"** (потом можно настроить правила)
4. Выбери регион (например `europe-west3` для Европы) → **"Включить"**

### Правила безопасности Firestore

После создания базы зайди в **Firestore → Правила** и замени на:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Пользователи: читать всем, писать только себе
    match /users/{uid} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.uid == uid;
    }

    // Стартапы: читать всем, писать авторизованным стартаперам
    match /startups/{startupId} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null &&
        (resource.data.ownerUid == request.auth.uid ||
         get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin');

      // Обновления стартапа
      match /updates/{updateId} {
        allow read: if true;
        allow write: if request.auth != null &&
          (get(/databases/$(database)/documents/startups/$(startupId)).data.ownerUid == request.auth.uid ||
           get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin');
      }

      // Команда стартапа
      match /team/{memberId} {
        allow read: if true;
        allow write: if request.auth != null &&
          (get(/databases/$(database)/documents/startups/$(startupId)).data.ownerUid == request.auth.uid ||
           get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin');
      }
    }

    // Приглашения
    match /invites/{inviteId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow update: if request.auth != null &&
        (resource.data.startupOwner == request.auth.uid ||
         resource.data.fromUid == request.auth.uid);
    }

    // Диалоги
    match /conversations/{convId} {
      allow read, write: if request.auth != null &&
        request.auth.uid in resource.data.participants;
      allow create: if request.auth != null;

      match /messages/{msgId} {
        allow read: if request.auth != null &&
          request.auth.uid in get(/databases/$(database)/documents/conversations/$(convId)).data.participants;
        allow create: if request.auth != null;
      }
    }

    // Админ: полный доступ
    match /{document=**} {
      allow read, write: if request.auth != null &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
  }
}
```

## ШАГ 5 — Включи Storage (для аватарок)

1. В левом меню → **Build → Storage**
2. Нажми **"Начать"**
3. Выбери **"Тестовый режим"** → **"Далее"** → регион → **"Готово"**

### Правила Storage

В **Storage → Правила** замени на:

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /avatars/{uid} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.uid == uid
        && request.resource.size < 3 * 1024 * 1024
        && request.resource.contentType.matches('image/.*');
    }
  }
}
```

## ШАГ 6 — Создай первого администратора

Администратора нельзя создать через UI (в целях безопасности). Сделай так:

1. Зарегистрируйся на платформе с любой ролью (например "Специалист")
2. Зайди в Firebase Console → **Firestore → Коллекция `users`**
3. Найди свой документ (по email)
4. Измени поле `role` с `user` на `admin`
5. Теперь у тебя есть полный доступ через `admin.html`

## ШАГ 7 — Публикация на GitHub Pages

### 7.1 Создай репозиторий

1. Зайди на https://github.com → **New repository**
2. Назови его `launchpad` (или любое другое имя)
3. Сделай репозиторий **Public**
4. Нажми **"Create repository"**

### 7.2 Загрузи файлы

**Способ А — через браузер (без установки Git):**
1. Открой репозиторий → **"uploading an existing file"**
2. Перетащи ВСЕ файлы платформы
3. Нажми **"Commit changes"**

**Способ Б — через Git (если установлен):**
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/launchpad.git
git push -u origin main
```

### 7.3 Включи GitHub Pages

1. В репозитории → **Settings**
2. В левом меню → **Pages**
3. В разделе **"Source"** выбери ветку `main` и папку `/ (root)`
4. Нажми **Save**
5. GitHub выдаст URL вида: `https://ВАШ_ЛОГИН.github.io/launchpad/`

⚠️ **Важно:** сайт появится через 1-3 минуты!

## ШАГ 8 — Добавь домен в Firebase Auth

Чтобы авторизация работала с GitHub Pages:

1. Firebase Console → **Authentication → Settings → Authorised domains**
2. Нажми **"Add domain"**
3. Добавь: `ВАШ_ЛОГИН.github.io`
4. Сохрани

## Частые проблемы

**❓ Авторизация не работает / ошибка CORS**
→ Убедись что добавил домен `github.io` в Firebase Auth → Settings → Authorised domains

**❓ Firestore Permission Denied**
→ Проверь правила в Firestore. В тестовом режиме правила открыты на 30 дней — после истечения нужно обновить

**❓ Аватарки не загружаются**
→ Проверь правила Storage. Убедись что файл меньше 3МБ и формат image/*

**❓ Страницы не грузятся на GitHub Pages**
→ Жди 1-3 минуты после включения Pages. Если не помогает — проверь что все файлы загружены в корень репозитория

**❓ Как поменять название платформы**
→ Найди "LaunchPad" в HTML файлах и замени на своё название. Основные места: `<title>`, `.nav__logo`, `hero__title`

## ШАГ 9 — Создай индексы Firestore (ОБЯЗАТЕЛЬНО)

Некоторые запросы требуют составных индексов. Без них чат и фильтры не будут работать.

### Способ А — автоматически (если установлен Firebase CLI)

```bash
npm install -g firebase-tools
firebase login
firebase init firestore
firebase deploy --only firestore:indexes
```

### Способ Б — вручную через консоль

Зайди в **Firebase Console → Firestore → Indexes → Composite** и создай:

| Коллекция | Поля | Тип |
|-----------|------|-----|
| `startups` | `ownerUid` ASC + `createdAt` DESC | Collection |
| `conversations` | `participants` ARRAY + `lastAt` DESC | Collection |
| `invites` | `startupOwner` ASC + `status` ASC | Collection |
| `invites` | `fromUid` ASC + `startupId` ASC + `status` ASC | Collection |
| `team` | `uid` ASC | Collection group |

> ⚠️ Индексы создаются 1-2 минуты. Пока идёт создание — запросы будут падать с ошибкой в консоли браузера. Это нормально.

## Как поставить аватарку (для пользователей)

Storage (платный) не используется. Вместо этого:

1. Загрузи фото на бесплатный хостинг:
   - **[imgur.com](https://imgur.com)** — бесплатно, без регистрации
   - **[postimages.org](https://postimages.org)** — прямые ссылки
   - **[imgbb.com](https://imgbb.com)** — бесплатно
2. Скопируй **прямую ссылку** на изображение (заканчивается на `.jpg`, `.png` и т.д.)
3. В профиле нажми на аватар → вставь ссылку → Сохранить
